# IT Shelter organization profile

`profile/README.md` is the public GitHub organization profile in Russian.
`profile/README_EN.md` provides the English version; `profile/README_RU.md` keeps
an earlier Russian link working. The page uses local banner and SVG link assets.

Edit the Markdown to update projects and links. Replace the banner when changing
visual identity. No external badge services, tokens, scheduled jobs or backend
are needed. Public image URLs point to this repository's `main` branch.

These files customize the organization profile; they do not define shared
community policies for other IT Shelter repositories.
