# Practical programming, AI and useful tools

**IT_SHELTER** is a Russian-language technology and education project.
We build open-source tools and help turn ideas into working software.

[Русский](https://github.com/IT-Shelter-Labs/.github/blob/main/profile/README.md)

## Our projects

| Project | What it helps with |
| :--- | :--- |
| **[Research First Builder](https://github.com/IT-Shelter-Labs/research-first-builder)** · Agent Skill · Preview | Research real software references and justify architecture with sources before your coding agent builds. |
| **[Shelter Humanizer](https://github.com/IT-Shelter-Labs/Shelter-Humanizer)** · Windows | AI-assisted text editing and hidden Unicode cleanup, with local models or an API. |
| **[Claude Mods](https://github.com/IT-Shelter-Labs/Claude-Mods)** · Claude Code | Mods for tracking context and usage limits, handing off tasks and working across sessions. |
